# 이미지·시각 자료 (API 키 없이)

## 원칙
- 외부 이미지 생성 API, 외부 AI 모델 호출은 쓰지 않는다.
- 저작권이 불분명한 이미지를 웹에서 가져오지 않는다.

## 1. 아이콘
- Lucide: `npm i lucide-react` 또는 CDN `https://unpkg.com/lucide@latest`
- 의존성을 늘리기 싫으면 필요한 아이콘만 inline SVG로 넣는다 (24x24, stroke=currentColor).

## 2. 로고·일러스트
- 단순한 도형 조합의 inline SVG를 직접 작성한다. 색은 디자인 토큰 변수 사용.
- 빈 화면 그림: 원/사각형 2~3개 + 아이콘 1개 정도로 충분하다.
- 파비콘: 같은 SVG를 `<link rel="icon" href="data:image/svg+xml,...">`로.

## 3. 사진 자리
- 실제 사진이 필요하면 CSS 그라데이션 + 이니셜/아이콘으로 대체하고 `가정:`으로 표시한다.
- 사용자 업로드 이미지가 있으면 그것을 우선 사용한다.

## 4. 차트
- 간단한 막대/선: inline SVG 직접 그리기 또는 Chart.js CDN 하나.
- 축 라벨, 단위, 출처를 넣는다. 색은 강조색 1개 + 회색.

## 5. 확인
- 다크/라이트 배경 모두에서 보이는지, 작은 크기(16~24px)에서도 알아보는지 확인한다.
